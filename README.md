# Rakesh Kannepelli — Engineering Portfolio & Client Portal

Official repository housing Rakesh Kannepelli's developer portfolio and freelance client acquisition portal.

---

## 📂 Architecture Overview

The repository is modularly organized into two dedicated applications:

```text
PORTFOLIO_FOR_ME/
├── index.html                 # Root gateway redirecting to /portfolio
├── portfolio/                 # Developer Portfolio (Bio, Skills, Projects, Experience)
│   ├── index.html
│   ├── src/
│   ├── public/
│   └── package.json
└── freelance/                 # Client Scope Advisory & Acquisition Portal
    ├── index.html
    ├── style.css
    ├── main.js
    ├── assets/
    └── package.json
```

---

### 1. Developer Portfolio (`/portfolio`)
- **Focus**: Technical biography, GitHub repositories, skills matrix, and career certifications.
- **Features**: Interactive GSAP animations, custom icon canvas, dark mode styling, and dynamic transition into the freelance client advisory portal.
- **Live Tech Stack**: HTML5, CSS3, JavaScript (ES6+), GSAP, Vite.

### 2. Freelance Client Acquisition Portal (`/freelance`)
- **Focus**: Converting Indian business owners and startup founders into clients with transparent builder pricing.
- **Features**:
  - **Skeuomorphic Design System**: Visme-inspired tactile palette (Deep Obsidian Slate, Charcoal, Rich Gold, Electric Blue) with physical bevels, specular lighting, and recessed wells.
  - **5 Distinct Service Models**: Custom Build From Scratch, Making Offline Business Digital, WooCommerce D2C Stores, Custom CRM Portals, and Corporate Lead Funnels.
  - **Interactive Natural Flow Specifier**: Order of deliverables following visitor journey, with inline "+ Add to Website Scope" capability.
  - **Smart Market-Standard Estimator**: Dynamic real-time calculation in ₹ INR and USD with realistic sprint timelines (**3-4 weeks minimum up to 8-12 weeks maximum**).
  - **Multi-Channel Submission**: Instant printable/downloadable executive PDF scope proposal, pre-filled WhatsApp routing (`+91 93987 94176`), and direct EmailJS integration.
  - **Cross-Platform**: 100% responsive for desktop and mobile with direction-aware touch swiping.

## 🚀 Local Development

To run either project locally:

```bash
# Developer Portfolio
cd portfolio
npm install
npm run dev

# Freelance Portal
cd freelance
npm install
npm run dev
```
